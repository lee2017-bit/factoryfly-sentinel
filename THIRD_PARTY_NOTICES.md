# Third-Party Components

FactoryFly Sentinel does not vendor the following projects. Evaluators install or
download them separately and must comply with their respective licences.

- COLMAP
- FFmpeg
- OpenCV
- Streamlit
- NumPy
- Pillow
- PyTorch
- ROCm
- DINOv2

The DINOv2 source repository and pretrained checkpoint are downloaded by
`scripts/setup_radeon_cloud.sh`.

No licence has been selected for the FactoryFly Sentinel project code in this
package. The repository owner should choose and add an appropriate `LICENSE`
file before describing the project itself as open-source.
